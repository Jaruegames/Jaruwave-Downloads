# Jaruwave — Downloads

Repositório oficial dedicado aos downloads experimentais do Jaruwave para Windows e Arch/CachyOS Linux.

Os instaladores serão disponibilizados em Releases. A primeira versão experimental está em preparação e ainda não foi publicada. O pacote Linux será adicionado posteriormente.

Este repositório contém somente materiais de distribuição. O código-fonte original permanece privado. Os pacotes Electron incluem JavaScript inspecionável.

Software experimental para testes entre amigos. Não há atualizações automáticas. Consulte as notas de cada versão e confira os hashes antes de instalar.
